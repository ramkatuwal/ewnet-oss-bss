# Retired Modules

**Status:** PURGED & DOCUMENTED

The following modules have been intentionally removed from the current baseline and are considered retired:
- FIM (Field Inventory Management)
- Geography
- Infrastructure
- Pole
- Duct
- Manhole
- Employee
- Designation

## Governance Rules for Retired Modules
1. Exclusion: These modules are not part of the current Phase 2 baseline.
2. No Restoration: Developers must not restore code, migrations, or models for these modules from old Git history.
3. Future Implementation: Any future implementation of these domains requires a new, explicit Architecture-controlled task.
4. FIM Status: FIM remains a future roadmap domain and is not a deleted business requirement, but its current codebase presence is retired to maintain architectural focus.
